# Studio IA - MVP 1

Estúdio web responsivo para criar prompts de vídeo realista. Não usa API paga e não gera vídeos diretamente.

## Requisitos
Node.js 20.9+ e npm.

## Iniciar
```bash
npm install
npm run dev
```
Abra http://localhost:3000

## Arquitetura
- Next.js App Router + TypeScript
- `app/page.tsx`: formulário e visualização do prompt
- `app/api/prompts/route.ts`: validação e geração de prompts
- `lib/prompt.ts`: regras de composição do prompt
- `app/style.css`: tema responsivo

## Próximas etapas
- Login e persistência de projetos (Supabase)
- Biblioteca de modelos com referências e consentimento
- Histórico e versões de prompts
- Integração opcional com provedores de geração de vídeo
- Multi-tenant, planos e pagamentos apenas após validar MVP

## Segurança
Não coloque chaves de API no frontend. Este MVP não possui autenticação nem armazenamento persistente e não deve ser publicado como serviço multiusuário sem essas implementações.

import {NextResponse} from 'next/server';
import {makePrompt, type PromptInput} from '../../../lib/prompt';
export async function POST(req:Request) {
  try {
    const body = await req.json() as PromptInput;
    if (!body || typeof body !== 'object' || ![8,10,15].includes(body.duration)) return NextResponse.json({error:'Duração inválida'}, {status:400});
    for (const field of ['model','product','scene','movement'] as const) if(typeof body[field] !== 'string' || body[field].length > 1000) return NextResponse.json({error:`Campo inválido: ${field}`},{status:400});
    if(typeof body.spoken !== 'boolean') return NextResponse.json({error:'Áudio inválido'}, {status:400});
    return NextResponse.json({prompt:makePrompt(body)});
  } catch {return NextResponse.json({error:'Requisição inválida'},{status:400})}
}

export type PromptInput = {model:string;product:string;scene:string;movement:string;duration:number;spoken:boolean};
export function makePrompt(x:PromptInput) {
  const duration = [8,10,15].includes(x.duration) ? x.duration : 10;
  return `Create a photorealistic ${duration}-second vertical 9:16 commercial fashion/product video. Subject: ${x.model.trim() || 'an adult presenter'}. Product/look: ${x.product.trim() || 'the featured outfit'}. Setting: ${x.scene.trim() || 'a natural indoor environment'}. Movement: ${x.movement.trim() || 'subtle natural weight shifts and relaxed gestures'}. Camera: handheld by another person, gentle natural micro-movements, realistic autofocus, stable framing, continuous shot. Preserve facial identity, anatomy, clothing details, product proportions and lighting consistency. Avoid exaggerated gestures, artificial skin, warped hands, morphing, abrupt cuts and text overlays. Audio: ${x.spoken ? 'natural Brazilian Portuguese dialogue, no subtitles' : 'no dialogue, ambient sound only'}. Show the outfit and product clearly without forced posing.`;
}
